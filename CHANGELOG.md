# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Added

- A 25-tool Windows computer-use MCP surface with localhost daemon and CLI.
- Canonical window, snapshot, screenshot, and zoom identity contracts.
- Windows.Graphics.Capture with screen-crop fallback and capture diagnostics.
- UIA, MSAA, OmniParser V2 YOLO, Florence-2, and RapidOCR observation pipeline.
- Recording/replay, human workflow learning, and mixed-tool CLI batch execution.
- Bundled vision and OCR models with offline runtime loading and integrity checks.

### Security

- Localhost-only defaults, daemon token authentication, restricted CORS, and
  explicit opt-in for CDP JavaScript.
